# Protocol for the second independently authored report-and-workbook pair (written 9 Nov 2026, before any result was read)

Data. `VPSC-Annual-Report-2019-to-2020-accessible-version.docx` (the Victorian Public Sector Commission's 2019-20 annual report, accessible Word version, 1.44 MB as listed on
its own site) and `VPSC-financial-statements-2020-21.xlsx` (the Commission's 2020-21 financial statements workbook, already used in the first pair). The scenario is the one a
real owner meets every period: **last period's report, this period's workbook**. The report quotes 2020 and 2019 figures; the workbook's 2020 column holds the 2020
comparatives of the next year's statements, and has no 2019 column. So 2020 figures in the report should link to the workbook's 2020 column (restated figures excepted), and
2019 figures have no source in this workbook.

Rules. No change to Workroom between this protocol and the run. One run, reported as it comes out; anything fixed afterwards is labelled non-blind. The report was not read
before this protocol.

Measured, in order. (1) Find links: figures found, linked automatically, asked, listed as coincidences, no source, and time. (2) Precision of the automatic links: every one
read by hand if there are 120 or fewer, otherwise the first 60 in document order by hand and the rest by a mechanical row-heading comparison with the flagged ones read; a
year check on every link where both sides carry a year (the report's 2020 must meet the workbook's 2020 column). (3) The release test, as in the first pair (up to 10
constant cells changed in the workbook XML, one release, the report read back and opened in the real Word, only the linked figures may differ). (4) Restatements: figures
that appear in the report with the same row heading and year as a workbook cell but a different value, listed, not linked.

Not covered: PowerPoint, charts, roll-forward, the 2019 column, claims in the report's prose. One more pair is two data points, not a rate; both pairs are from one agency.
